# 実績管理アプリ（入口ページ）

下垣綾子さん・青柳和馬さんの実績管理アプリを開くための、入口の1ページ。

アプリ本体とデータは Google Apps Script 側にあり、ここには置いていない。
このページがやっているのは、アプリを枠の中に読み込むことだけ。

- 給与のデータは入っていない
- 暗証番号も入っていない（アプリ側で確かめている）
- 検索避け（noindex）を指定している

枠に入れているのは、Google のURLを直接開くと
「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」
という帯が毎回出るため。包むと出ない。
